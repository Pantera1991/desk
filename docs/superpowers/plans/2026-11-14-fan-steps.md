# Fan Steps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace "fans at full speed from one limit" with up to four user-set steps ("from X°C → Y% of max"), with hysteresis, in a mode list of four.

**Architecture:** The root helper learns `level N` (N from a fixed list, mirrored exactly in the sudoers rule) instead of `max`. In thermal.rs a step policy turns the averaged temperature into a step index (up at once, down 7°C lower and a minute apart). `Fans` sends the step's percent to the helper. Layout stores `fanSteps` and migrates `fanLimit`/`fansFirst`. Options edits the table; the chip shows `74° ≋ 70%`.

**Tech Stack:** Rust (Tauri 2, IOKit SMC via `fan_control.rs`/`smc.rs`, helper crate `src-tauri/fans-helper`), TypeScript (vanilla DOM, vitest).

**Spec:** `docs/superpowers/specs/2026-11-14-fan-steps-design.md`. It builds on `docs/superpowers/specs/2026-11-14-fans-on-overheat-design.md` and on PR 43 (helper rounds with read-back, `Keys` for M5, `probe`).

## Global Constraints

- **Fans only on the user's explicit request.** The default mode stays `"slow"`. No migration, update or first start may pick a fan mode or install the helper or rule. No toast or hint may nudge towards fans.
- **Levels** are exactly `40, 50, 60, 70, 80, 90, 100` (% of each fan's `FnMx`). The target is never below the fan's `FnMn` when that key reads.
- **Steps:** 1 to 4. `celsius` is 50–100 and strictly ascending. `percent` comes from the level list and never decreases. The default is `[{celsius: 70, percent: 100}]`.
- **Timing (unchanged from thermal.rs):**
  - an average of 3 readings, 5 s apart;
  - down only at `≤ threshold − 7°C` (`COOL_MARGIN`), and at least 60 s after the last change (`MIN_SLOW`);
  - up at once.
- **Sudoers rule** lists exactly `HELPER level 40` … `HELPER level 100` and `HELPER auto`, with no wildcards. The helper accepts nothing else that touches the SMC.
- `fan_control::PROTOCOL = 3`.
- **Modes:** `off | slow | together | fans`. `"fansFirst"` read from old files becomes `together`.
- **Language and naming:**
  - Polish UI copy lives in `src/locales/pl.ts`; English goes in `src/locales/en.ts` with the same placeholders (`src/i18n.test.ts` checks this).
  - Code and comments are in English.
  - Commit subjects are in English, in the repo's sentence style (e.g. "The fans reach full speed on M3 and M5 Macs"); commit bodies are in Polish.
  - No mention of AI assistance anywhere.
- **Checks:**
  - `pnpm check` must pass before each commit: typecheck, eslint, vitest, `cargo clippy --all-targets -D warnings`, `cargo test`.
  - Helper crate: `cd src-tauri/fans-helper && cargo test && cargo clippy --all-targets -- -D warnings`.
- **Platforms:** Windows and Linux must still compile. The fan code keeps its existing `cfg` stubs.
- **Base branch:** `feat/fan-steps` sits on top of PR 43 (`fix/fans-apple-silicon-unlock`). Rebase onto `main` once PR 43 is merged.

## Review Focus

1. **The table is edited while desk holds a step.** For example, the held row is deleted or a preset has fewer rows. Desk must not panic or use a stale index. It recomputes the step: up at once, down with hysteresis. *(Task 3: `edited_table_clamps_the_held_step`.)*
2. **The sensor stops reading while the fans are at a step.** The fans go back to auto after the minute instead of staying manual forever. *(Task 3: `a_lost_sensor_gives_the_fans_back_after_the_minute`.)*
3. **`layout.json` holds a broken table.** Examples: unsorted rows, 45%, 120°C, six rows, an empty list. It loads repaired and never fails startup. *(Task 3: `normalize_repairs_any_table`; Task 4: `broken_steps_in_the_file_are_repaired`.)*
4. **Something runs the helper with a malformed level.** Examples: `level`, `level 45`, `level 070`, `level 70 x`, `max`. The helper exits with code 2 without opening the SMC. *(Task 1: `parse_accepts_only_the_listed_commands`.)*
5. **A threshold is half typed in Options.** For example, "7" on the way to "75". The table is not saved; a red line says why. *(Task 5: `stepsProblem` cases.)*
