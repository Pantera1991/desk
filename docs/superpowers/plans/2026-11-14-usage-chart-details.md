# Usage Chart Details Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The 24-hour chart in the usage popover says what each bar holds on hover and, on click, which models filled the 5-hour window up to that bar.

**Architecture:** The transcript scanner keeps each message's model and tokens; a new command `usage_models` sums cost and tokens per model over a time range. `bars24h` also returns each bar's range and window start. The view renders the bars as buttons, a hover line and a picked-bar panel; the popover keeps the pick and its answer across redraws.

**Tech Stack:** Tauri 2 (Rust), TypeScript, vitest.

**Spec:** `docs/superpowers/specs/2026-11-14-usage-chart-details-design.md`

## Global Constraints

- Breakdown range: from the bar's 5-hour window start to the bar's end, messages with `from ≤ t < to`.
- Rows sorted by cost, highest first; models with 0 tokens left out.
- Only Claude accounts; for any other agent `usage_models` returns an empty list.
- The new command is listed in `src-tauri/build.rs` COMMANDS and `capabilities/default.json` (`allow-usage-models`); its generated `permissions/autogenerated/usage_models.toml` is committed like the other 57.
- Copy (pl / en): hover `"{from}–{to} · {pct} okna 5 h (okno od {start})"` / `"{from}–{to} · {pct} of the 5 h window (window from {start})"`, without a start `"{from}–{to} · {pct} okna 5 h"` / `"{from}–{to} · {pct} of the 5 h window"`; panel head `"Okno od {start} do {to}: {cost} · {tokens} tokenów"` / `"Window from {start} to {to}: {cost} · {tokens} tokens"`; empty `"brak sesji Claude Code w tym czasie"` / `"no Claude Code sessions in this time"`; default line `"Najedź na słupek; kliknij, żeby zobaczyć modele."` / `"Hover a bar; click it to see the models."`.
- Cost as `$41.20` (API prices); tokens as `7.1K`, `2.4M`, `120M`, `1.4B` (one decimal below 10).
- Esc closes the panel first, the popover on the next press.
- Code and comments in English; commit subjects English, bodies Polish; no AI attribution.

## Review Focus

1. **The popover redraws while a bar is picked** (every refresh, the read time ticking): the panel and the highlight stay, and the answer is not asked again. *(Task 4: `the pick survives a redraw` view test.)*
2. **A bar whose window began more than a day ago or before desk recorded** (`start` older than 24 h): the range still starts at the window start; the scanner reads files modified since `from`. *(Task 1: `models_reach_back_to_the_window_start`.)*
3. **The same message written on several blocks** (Claude Code repeats usage): counted once, with its last usage. *(Task 1: `models_count_a_message_once`.)*
4. **A transcript without `model`, or `<synthetic>` with zero usage:** no empty or zero row. *(Task 1: `models_leave_out_zero_token_rows`.)*
5. **The ACL refuses the new command from desk's page** (the bug PR "usage details ACL" fixed): the main window may call `usage_models`. *(Task 2: `the_main_window_can_ask_for_models`.)*

  - `models_leave_out_zero_token_rows`: a `<synthetic>` message with all-zero usage and one with no `model` and zero usage → empty result.

- [ ] **Step 3: Implement.** `take` stores model and `tokens = input + write_5m + write_1h + read + output`; `models` walks `transcripts(projects_dir)`, skips files modified before `from`, `read_on`, sums by model over `from ≤ at < to`, drops rows with `tokens == 0`, sorts by cost desc then name.
