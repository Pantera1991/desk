# Docker side panel, restart and deploy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the Docker tree from a popover into a side panel (⌘G / Ctrl+Shift+G), add per-container restart, and add "Wdróż" (compose up from the folder of the matching open card) in a tile.

**Architecture:** Rust gains `proc::run` (the timeout runner moved out of docker.rs), `docker_restart`, `git_status_summary`, a `working_dir` label on containers, and a `deploy` tile kind whose command is built in Rust only for a folder that has a compose file. TS turns `DockerPopover` into a `DockerPanel` aside in `.middle` (between `.stage` and the files panel) with the same polling logic, and wires restart/deploy through `confirmBox`.

**Tech Stack:** Tauri 2, Rust, TypeScript, vitest.

**Spec:** `docs/superpowers/specs/2026-11-18-docker-side-deploy-design.md` (+ `2026-11-18-docker-restart-design.md`, base `2026-11-18-docker-panel-design.md`)

- Done means `pnpm check` passes.
