# Find in Files Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PhpStorm-style "Find in Files" inside desk's files panel: a shortcut, live hits with highlighted matches, a preview below, and Enter opening the file at the line in the built-in editor or in an editor command set in Options.

**Architecture:**
- Rust gets a new `grep.rs`. It runs `git grep -n` (or walks the files when the project has no git) and returns hits with UTF-16 highlight ranges computed with the `regex` crate.
- Rust gets `open_file_at`, which launches the configured editor at a line without a shell.
- The TS files panel (`Side`) gets a search mode (`find-panel.ts`) with pure helpers in `find-view.ts`. The existing CodeMirror editor learns read-only mode and go-to-line.

**Tech Stack:** TypeScript (vanilla DOM, CodeMirror 6, vitest), Rust/Tauri 2, `git grep`, `regex` crate.

**Spec:** `docs/superpowers/specs/2026-11-19-find-in-files-design.md`

## Global Constraints

- **Where to work:** branch `feat/find-in-files`, checkout `.claude/worktrees/find`. Run every command from `desk-main` with literal relative paths: no `cd`, no shell variables for paths, no `source`.
- **Node:** 26, as in `.nvmrc`.
- **Commits:** messages in Polish, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Restore `src-tauri/permissions/autogenerated` line-ending churn before committing (`git -C .claude/worktrees/find checkout -- src-tauri/permissions/autogenerated`). Commit only the new `*.toml` files that a new command generates.
- **Privacy:** no server names, key names or `/home/<user>` paths in comments, commits, docs or fixtures.
- **Text and sizes:** UI text in `src/locales/pl.ts` and `en.ts`; Rust messages via `tr!(pl, en)`. New CSS sizes use `calc(<N>px * var(--ui-scale, 1))`.
- **Shortcut** `findInFiles`: mac `Super+Shift+KeyF`, other `Control+Alt+Shift+KeyF`, group `window`.
- **Search:**
  - `git --no-optional-locks -c core.fsmonitor=false grep -n -I --untracked --no-color --max-count=50` plus `-i` (case off), `-w` (word), `-E` (regex) or `-F`, then `-e <query>`;
  - 5 s timeout;
  - at most 500 hits in total and 50 per file;
  - a line is trimmed to about 200 characters around its first match, with "…".
- **Editor command:** characters `[A-Za-z0-9/._~-]` only, no spaces. A leading `~/` is expanded. Editor args by program file name:
  - `subl`, `zed`: `file:line`;
  - `code`, `cursor`, `codium`: `--goto file:line`;
  - `phpstorm`, `idea`, `webstorm`, `pycharm`, `goland`, `rider`, `clion`: `--line N file`;
  - anything else: `file`.
- **Default editor:** `layout.fileEditor = ""` means the built-in editor. The tree's double-click follows the same setting.

## Review Focus

1. **A query starting with `-`** (e.g. `--version`) is searched as text and never read as a git option. Test in Task 1.
2. **Polish letters and emoji before a match** (`zażółć 😀 pre`): the highlight ranges are UTF-16 code units, so `<mark>` lands on `pre`. Test in Task 1 (Rust ranges) and Task 3 (row HTML).
3. **A very long minified line** (one 50 000-char line) is trimmed around the match and its ranges shifted. Test in Task 1.
4. **Typing fast:** a slow answer to an older query never replaces a newer one. Test in Task 3 (`Latest`).
5. **An editor command like `subl; rm -rf ~`** or with spaces is refused at save and at open. Test in Task 2.

### Task 1: Rust search (`grep.rs`) and the `grep_files` command

**Files:**
- Create: `src-tauri/src/grep.rs` (with `mod tests`)
- Modify: `src-tauri/Cargo.toml` (add `regex = "1"`); `src-tauri/src/lib.rs` (mod, command, `generate_handler!`); `src-tauri/build.rs`; `src-tauri/capabilities/default.json` (`allow-grep-files`)
- Optionally modify `src-tauri/src/proc.rs` if a status-aware runner is needed, see Step 3.

**Interfaces:**
- Produces:
  - `#[derive(Serialize, Default, Clone, Copy)] #[serde(rename_all = "camelCase")] pub struct GrepOptions { pub case: bool, pub word: bool, pub regex: bool }`
  - `#[derive(Serialize, Debug, PartialEq)] #[serde(rename_all = "camelCase")] pub struct GrepHit { pub file: String, pub line: u32, pub text: String, pub marks: Vec<[u32; 2]> }` (`marks`: UTF-16 `[start, end)` in `text`)
  - `#[derive(Serialize, Debug, Default)] #[serde(rename_all = "camelCase")] pub struct GrepResult { pub hits: Vec<GrepHit>, pub files: u32, pub more: bool }`
  - `pub fn grep(root: &Path, query: &str, opts: GrepOptions) -> Result<GrepResult, String>`
  - `pub fn pattern(query: &str, opts: GrepOptions) -> Result<regex::Regex, String>`. It escapes unless `regex`, wraps in `\b…\b` for `word`, adds `(?i)` unless `case`. A bad regex gives `Err(tr!("zły regex: …", "bad regex: …"))`.
  - `pub fn marked_line(line: &str, re: &regex::Regex) -> (String, Vec<[u32; 2]>)`, which trims and computes ranges.
  - Tauri command `grep_files(path: String, query: String, case: bool, word: bool, regex: bool) -> Result<GrepResult, String>` (async, `spawn_blocking`).

### Task 2: Rust editor setting and `open_file_at`

- Modify: `src-tauri/src/layout.rs` (`file_editor: String`, default `""`, round-trip test); `src-tauri/src/lib.rs`, `build.rs`, `capabilities/default.json` (`allow-open-file-at`, `allow-check-file-editor`)

**Interfaces:**
- Produces:
  - `pub fn valid_command(cmd: &str) -> bool`: non-empty, `[A-Za-z0-9/._~-]` only, not starting with `-`.
  - `pub fn resolve(cmd: &str, home: &Path) -> Result<PathBuf, String>`. It expands `~/`. A command containing `/` must be an existing file; anything else goes through `crate::agents::which`. If nothing is found it gives `Err(tr!("nie ma programu {cmd}", "no program {cmd}"))`.
  - `pub fn args(program: &Path, file: &Path, line: u32) -> Vec<OsString>`, using the families from the Global Constraints and keyed by the file name.
  - Tauri `open_file_at(app, path: String, file: String, line: u32) -> Result<(), String>`:
    - reads `layout.file_editor`, which must be non-empty, else `Err`;
    - checks it with `valid_command`, resolves it and runs `project::inside(path, file)`;
    - spawns `Command::new(program).args(args)` with no shell.
  - Tauri `check_file_editor(cmd: String) -> Result<(), String>`, which runs `valid_command` and `resolve`. Options calls it before saving.

    - `find.count`: plural via `tn`, e.g. „{n} trafienie|{n} trafienia|{n} trafień” „w {files} plikach” / "{n} match|{n} matches" "in {files} files"
